# MyFences

自己用的 [Stardock Fences](https://www.stardock.com/products/fences/) 風格桌面整理工具，Windows 10 / 11，C# / WPF（.NET 8）。

## 功能

### 桌面接管
MyFences 執行時會關掉 Windows 的「顯示桌面圖示」，改由自己畫桌面圖示（結束時還原）。每個桌面項目只有一個家：**在某個分區裡，或在桌面上的某個位置**，不會重複、也不會不見。

| 操作 | 效果 |
|---|---|
| 桌面空白處按右鍵 | **Windows 原本的桌面選單**（新增、貼上、顯示設定、個人化…）；新增 / 貼上的東西會出現在按右鍵的位置 |
| 在空白處拖曳 | 框選桌面圖示 |
| 圖示：雙擊、Enter | 開啟 |
| 圖示：右鍵 | 開啟、開啟方式、在檔案總管中顯示、剪下、複製、放進分區、刪除、重新命名、內容——動作都交給 Windows 做 |
| Delete / Shift+Delete | 刪除到資源回收筒 / 永久刪除（跟著資源回收筒的確認設定） |
| Ctrl+C / X / V | 複製 / 剪下 / 貼上，可以跟檔案總管互相貼 |
| F2、Ctrl+Shift+N、Alt+Enter | 重新命名、新增資料夾、內容 |
| 拖曳圖示 | 換位置（對齊格線）；拖到資料夾 / 資源回收筒 = 搬進去 / 刪除；拖到檔案總管或其他程式跟從桌面拖出去一樣 |
| 雙擊桌面空白處、Ctrl+Alt+F | 隱藏 / 顯示所有分區和桌面圖示 |

### 分區
| 操作 | 效果 |
|---|---|
| 在桌面 **Ctrl + 左鍵拖曳** | 畫出新分區，框住的圖示直接放進去，放開後輸入名稱 |
| 把圖示拖進 / 拖出分區 | 放進分區 / 放回桌面上放開的位置 |
| 分區裡的圖示 | 一樣可以右鍵（開啟、剪下、複製、刪除、內容、放回桌面）、Delete、Ctrl+C / X / V |
| 拖曳標題列 | 移動分區；會自動對齊螢幕邊緣和其他分區（按住 Alt 暫時不對齊）；被蓋住的桌面圖示會自動讓開 |
| 雙擊分區名稱 / 分頁名稱 | 直接改名（Enter 確定、Esc 取消；F2 也可以改分區名稱） |
| 雙擊標題列空白處 | 收合；滑鼠停在收合的分區上 0.3 秒會暫時展開 |
| 滑鼠移到標題列 | 出現按鈕：新增分頁、外觀（顏色、自選顏色、透明度、圖示大小、毛玻璃、淡化）、收合、更多 |
| 滑鼠移到分頁標籤 | 出現 ✕，點一下刪除分頁（裡面的項目移到旁邊的分頁） |
| 拖曳分頁標籤 | 調整分頁順序 |
| 把資料夾拖到分區標題列 | 空的分區直接變成資料夾分區；有東西的分區會在旁邊另外建一個資料夾分區 |
| **Ctrl + Z** 或右下角提示的「復原」 | 復原分區相關的動作（刪除分區 / 分頁、放進 / 拿出、整理桌面、還原快照） |
| Ctrl+Alt+← / →、點桌面底部的圓點 | 切換桌面頁面（分區每頁不同；分區外的桌面圖示每頁都顯示） |

### 外觀
- **跟隨系統配色**：預設跟著 Windows 淺色 / 深色模式，選取與提示用系統強調色；也可以選強調色或其他顏色
- 文字顏色依背景明暗自動切換；半透明背景、毛玻璃、平常淡化

### 整理
- **自動整理規則**（分區 ⋯ →「自動整理規則…」或設定視窗）：用卡片組條件，不用背語法
  - 條件：副檔名（可一次填好幾個）、檔名包含、資料夾、任何檔案、最近幾天修改、超過幾天沒動、檔案大小
  - 一張卡片裡的條件是「而且」，卡片之間是「或」；一鍵加入「捷徑、文件、圖片、影片、壓縮檔、安裝檔」
  - 編輯時即時顯示桌面上有幾個項目符合；可設定規則優先順序
- 桌面出現新檔案時自動依規則整理；桌面檔案改名時分區跟著更新
- **分頁**：一個分區放好幾組圖示；按 ＋ 新增後直接輸入名稱，把圖示拖到分頁標籤上就移過去
- **資料夾分區**：即時顯示某個資料夾的內容
- **桌面頁面**：每頁放不同的分區
- **快照**：手動建立、每天自動一份、整理和還原前自動備份；在設定視窗還原

### 其他
- 多螢幕 / 換解析度時分區自動換算位置，記住每一種螢幕組合的版面
- 按 Win+D 時分區仍留在桌面上；開機自動啟動
- **設定視窗**（系統匣 →「設定…」）：一般開關、規則總覽、快照、操作說明

## 安裝 / 執行

### 直接下載

每次推到 `main`，GitHub Actions 會建一個單一 exe：到 repo 的 **Actions** → 最新一次 `build` → 下載 `MyFences-win-x64`，解壓後執行 `MyFences.exe`（self-contained，不用另外裝 .NET）。

- 瀏覽器擋下載時：到 `chrome://downloads` 選「保留」
- Windows 跳出 SmartScreen 時：對 exe 按右鍵 →「內容」→ 勾「解除封鎖」，或在警告視窗按「其他資訊」→「仍要執行」
- 建議把 exe 放在固定的位置（例如 `%LOCALAPPDATA%\MyFences\`），「開機時啟動」會記住 exe 的位置

### 自己 build

需要 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)：

```powershell
dotnet run --project src/MyFences
# 或發佈成單一 exe
dotnet publish src/MyFences -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o publish
```

也可以用 Visual Studio 2022 開 `MyFences.sln`。

## 設定檔

`%AppData%\MyFences\config.json`（系統匣 →「開啟設定資料夾」）。分區位置、項目、規則都在這裡，可以直接備份或手動編輯（編輯前先結束程式）。

## 運作方式

- 每個螢幕有一層透明的「桌面圖示層」，分區外的圖示畫在上面；空白處完全透明，滑鼠會直接點到 Windows 原本的桌面，所以空白處的右鍵選單、桌布、桌面小工具都是原本的
- 分區永遠在桌面圖示層上面、一般視窗下面；按 Win+D 也不會被縮小
- 刪除、複製、搬移、內容、開啟方式都是呼叫 Windows 自己的功能（一樣有進度視窗、衝突詢問、可以從資源回收筒還原）
- 不會注入檔案總管，也不會改檔案屬性；舊版本設成隱藏的檔案，啟動時會自動還原

## 已知限制

- 桌面空白處右鍵選單裡的「檢視」「排序方式」只影響被關掉的 Windows 桌面圖示；MyFences 的圖示大小、自動排列、對齊格線在 設定 → 一般
- 第一次啟動時桌面圖示會依名稱重新排列（之後會記住你擺的位置）
- 結束 MyFences 會還原 Windows 的桌面圖示；如果 MyFences 當掉，重新開啟再結束即可還原
- 從 Windows 選單「新增」的項目會在按右鍵的位置出現並進入改名
- 多螢幕的 DPI 縮放不同時，分區跨螢幕換算後大小可能略有誤差
