# MyFences

自己用的 [Stardock Fences](https://www.stardock.com/products/fences/) 風格桌面整理工具，Windows 10 / 11，C# / WPF（.NET 8）。

## 功能

### 基本操作
| 操作 | 效果 |
|---|---|
| 在桌面 **Ctrl + 左鍵拖曳** | 畫出新分區，放開後直接輸入名稱 |
| 把桌面圖示拖進分區 | 加入分區，自動排整齊；放不下時分區自動長高 |
| 把圖示拖出分區 | 移出分區，變回一般的桌面圖示 |
| 雙擊、右鍵、多選圖示 | 就是 Windows 桌面原本的操作——分區裡放的是**真正的桌面圖示**，檔案完全不會被修改 |
| 拖曳標題列 | 移動分區；會自動對齊螢幕邊緣和其他分區（按住 Alt 暫時不對齊） |
| 雙擊分區名稱 / 分頁名稱 | 直接改名（Enter 確定、Esc 取消；F2 也可以改分區名稱） |
| 雙擊標題列空白處 | 收合；滑鼠停在收合的分區上 0.3 秒會暫時展開 |
| 滑鼠移到標題列 | 出現按鈕：新增分頁、外觀（顏色、自選顏色、透明度、圖示大小、毛玻璃、淡化）、收合、更多 |
| 滑鼠移到分頁標籤 | 出現 ✕，點一下刪除分頁（裡面的項目移到旁邊的分頁） |
| 拖曳分頁標籤 | 調整分頁順序 |
| 把資料夾拖到分區標題列 | 空的分區直接變成資料夾分區；有東西的分區會在旁邊另外建一個資料夾分區 |
| **Ctrl + Z** 或右下角提示的「復原」 | 復原刪除分區 / 分頁、整理桌面、還原快照 |
| 雙擊桌面空白處、Ctrl+Alt+F | 隱藏 / 顯示所有分區 |
| Ctrl+Alt+← / →、點桌面底部的圓點 | 切換桌面頁面（兩頁以上才會出現圓點） |

### 外觀
- **跟隨系統配色**：預設跟著 Windows 淺色 / 深色模式，選取與提示用系統強調色；也可以選強調色或其他顏色
- 文字顏色依背景明暗自動切換；半透明背景、毛玻璃、平常淡化

### 整理
- **自動整理規則**（分區 ⋯ →「自動整理規則…」或設定視窗）：用卡片組條件，不用背語法
  - 條件：副檔名（可一次填好幾個）、檔名包含、資料夾、任何檔案、最近幾天修改、超過幾天沒動、檔案大小
  - 一張卡片裡的條件是「而且」，卡片之間是「或」；一鍵加入「捷徑、文件、圖片、影片、壓縮檔、安裝檔」
  - 編輯時即時顯示桌面上有幾個項目符合；可設定規則優先順序
- 桌面出現新檔案時自動依規則整理；桌面檔案改名時分區跟著更新
- **分頁**：一個分區放好幾組圖示；按 ＋ 新增後直接輸入名稱，把圖示拖到分頁標籤上就移過去
- **資料夾分區**：即時顯示某個資料夾的內容
- **桌面頁面**：每頁放不同的分區
- **快照**：手動建立、每天自動一份、整理和還原前自動備份；在設定視窗還原

### 其他
- 多螢幕 / 換解析度時分區自動換算位置，記住每一種螢幕組合的版面
- 按 Win+D 時分區仍留在桌面上；開機自動啟動
- **設定視窗**（系統匣 →「設定…」）：一般開關、規則總覽、快照、操作說明

## 安裝 / 執行

### 建議：在自己電腦上建置（不會被瀏覽器 / SmartScreen 攔）

MyFences 沒有程式碼簽章，從網路下載的 exe 會被 Chrome、Edge 和 Windows SmartScreen 當成「不常見的檔案」攔下來。
在自己電腦上用原始碼建置就沒有這個問題：

1. 在 GitHub repo 頁面按 **Code → Download ZIP**，解壓縮（或用 `git clone`）
2. 在解壓後的資料夾開 PowerShell，執行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\install.ps1
   ```
3. 腳本會自動安裝 .NET 8 SDK（第一次）、建置、裝到 `%LOCALAPPDATA%\MyFences`、建立開始功能表捷徑並啟動

要更新時，拿到新版原始碼再執行一次即可，設定檔不受影響。

### 直接下載 exe

每次推到 `main`，GitHub Actions 會建一個單一 exe：到 repo 的 **Actions** → 最新一次 `build` → 下載 `MyFences-win-x64`。
瀏覽器擋下載時，到 `chrome://downloads` 選「保留」；執行前對 exe 按右鍵 →「內容」→ 勾「解除封鎖」。

### 自己 build

需要 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)：

```powershell
dotnet run --project src/MyFences
# 或發佈成單一 exe
dotnet publish src/MyFences -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

也可以用 Visual Studio 2022 開 `MyFences.sln`。

### 關於「沒有簽章」的警告

這些警告看的是「發行者簽章」和「下載的人數（信譽）」，不是程式內容，所以改程式碼沒辦法完全消除。
要讓下載的 exe 不被攔，只能購買程式碼簽章憑證（例如 Azure Trusted Signing）或把 repo 公開後申請開源專案的免費簽章（例如 SignPath Foundation）。

## 設定檔

`%AppData%\MyFences\config.json`（系統匣 →「開啟設定資料夾」）。分區位置、項目、規則都在這裡，可以直接備份或手動編輯（編輯前先結束程式）。

## 運作方式

- 分區裡的圖示是檔案總管畫的**真正的桌面圖示**：MyFences 透過 Windows 公開的桌面介面（IFolderView）把它們排進分區的格子，分區移動時跟著移動
- 分區的標題列在圖示上面；分區底色畫在圖示後面的「桌布層」，所以圖示點得到、操作跟平常一樣
- MyFences 執行時會關掉桌面的「自動排列圖示」和「將圖示對齊格線」，結束時還原；不會注入檔案總管

## 已知限制

- **收合、分頁、桌面多頁、雙擊隱藏是實驗功能**：做法是把圖示暫時移到螢幕外。如果 Windows 不允許，MyFences 會提示並改成讓圖示留在原處；圖示萬一卡在螢幕外，到設定 →「找回跑到螢幕外的圖示」
- 分區裡不能捲動（圖示由檔案總管畫，沒辦法裁切）；放不下時分區會自動長高
- 只有桌面上的檔案能放進分區；從其他資料夾拖檔案進來時，放在分區中間（檔案會被放到桌面上並自動加入）
- 新檔案出現在分區範圍內時：如果你的游標正在那個分區上（剛拖進來的），會加入分區；否則（例如程式存檔到桌面）會被移到旁邊的空位
- 在桌面按住 Ctrl 點圖示（Explorer 原本的多選）會被拿來畫分區，桌面多選請改用拖框
- 多螢幕的 DPI 縮放不同時，分區跨螢幕換算後大小可能略有誤差
